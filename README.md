# TechStore — практическая работа по вёрстке

Учебная страница условного интернет-магазина электроники **TechStore**.
Курс «Frontend Development», РТУ МИРЭА.
Выполнил: **Мурад Асланов, группа БСБО-23-24**.

**Демо:** https://aamrx1.github.io/mirea-frontend-techstore/

## Цель

Закрепить на практике: семантические теги HTML5, сложные и комбинированные
CSS-селекторы, Flexbox, CSS Grid и CSS-переменные для темизации.

## Стек

Чистые HTML + CSS. JavaScript (≈40 строк) — только для переключения
светлой/тёмной темы; вся перекраска сделана через CSS-переменные.

## Структура файлов

```
index.html        — разметка страницы
css/style.css     — все стили (разделы пронумерованы в оглавлении в начале файла)
js/theme.js       — переключатель темы
images/           — SVG-иллюстрации товаров, логотип
```

## Где что применено

| Требование | Где в коде |
|---|---|
| Семантика HTML5 | `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `figure`, `address`, `data` |
| Иерархия заголовков | `h1` — первый экран, `h2` — секции/сайдбар/подвал, `h3` — карточки и блоки |
| `alt` у изображений | у всех `<img>` (логотип, hero, 8 товаров, товар дня) |
| Псевдоклассы | `a:hover`, `button:focus`, `:focus-visible`, `:active`, `article:nth-child(even)`, `:not(:last-child)`, `:checked`, `:invalid`, `:placeholder-shown`, `:focus-within` |
| Комбинаторы и атрибуты | `+`, `~`, `>`, потомок, `[data-badge]`, `[aria-current="page"]`, `::before`/`::after` + `attr()` |
| Flexbox | меню в шапке, hero, секция «Преимущества», карточки внутри, подвал |
| CSS Grid | сетка «Популярные товары» (`auto-fill` + `minmax`), общий макет `main` с областями `grid-template-areas` |
| Сайдбар в Grid | `<aside>` занимает область `sidebar` рядом с товарами |
| CSS-переменные | цвета, отступы, размеры шрифтов, радиусы, тени; тёмная тема — `[data-theme="dark"]` |
| Hover-анимации | карточки товаров (`translateY` + `box-shadow`, `scale` картинки), кнопки (`scale`), преимущества, ссылки |

## Запуск локально

Достаточно открыть `index.html` в браузере.
